# Quiz Portal

A modern and responsive **Quiz Portal** designed to provide an interactive and user-friendly online quiz experience.

## 📌 Project Status

🚧 **Currently in Development**

The main UI and required pages of the Quiz Portal have been created.
The **question display and quiz-question functionality are not available yet** and will be added in a future update.

## ✨ Features

* 🏠 Home Page
* 🔐 Login Page
* 📝 Signup Page
* 📊 Dashboard
* 👤 User Profile
* 📞 Contact Page
* 🎯 Quiz Page UI
* 📱 Responsive Design
* 🎨 Clean and User-Friendly Interface

## 🎯 Current Functionality

The project currently includes the basic structure and user interface for the Quiz Portal.

Users can navigate through different pages such as:

* Home
* Login
* Signup
* Dashboard
* Profile
* Quiz
* Contact

### ⚠️ Quiz Questions

**Quiz questions are not displayed at the moment.**

The `Quiz.html` page currently contains the quiz interface, but the actual questions and question-answer functionality are **yet to be implemented**.

Future updates will include:

* Adding quiz questions
* Multiple-choice options
* Answer selection
* Score calculation
* Next/Previous question functionality
* Quiz result page

## 🚀 Future Improvements

* Add a question database

* Add timer functionality
* Calculate and display scores

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `Home.html` in a web browser.
4. Navigate through the available pages.

No additional installation is required for the current version.

## 📈 Project Goal

The goal of this project is to develop a complete online quiz platform where users can register, log in, participate in quizzes, answer questions, and view their results.
